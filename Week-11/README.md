# Week 11 - Naive Bayes Classifier

This directory contains the Week 11 lab work for the Machine Learning course.

## Overview
- **Notebook**: `Week11_Naive_Bayes_Classifier.ipynb`
- **Topics Covered**: Bayes' Theorem, Gaussian Naive Bayes implementation using Scikit-Learn, decision boundary visualization on the Iris dataset, and model evaluation (Accuracy, Precision, Recall, F1-score).

## Execution
The notebook is designed to be run in a standard Jupyter environment or Google Colab.
