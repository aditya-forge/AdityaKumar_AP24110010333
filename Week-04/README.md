# 📊 Week 04 — Statistics & EDA Hands-On: Understanding Your Data Before Modeling

This directory contains the **Week 04** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: `Statistics_EDA_HandsOn_Student_Lab_Completed.ipynb`

The lab covers statistical foundations and Exploratory Data Analysis (EDA) techniques essential for diagnosing and understanding data distributions prior to machine learning model development:

| Topic | Description |
|---|---|
| **Descriptive Statistics** | Mean, median, variance, standard deviation, and skewness beyond `.describe()` |
| **Visualizing Distributions** | Histograms, KDE, boxplots, identifying normal vs. skewed distributions |
| **Correlation Analysis** | Pearson correlation coefficient, correlation matrices, and heatmap visualization |
| **Hypothesis Testing** | Independent two-sample t-test, null hypothesis formulation, and p-value interpretation |
| **Confidence Intervals** | 95% confidence interval estimation, standard error of the mean (SEM), and margin of error |
| **Mini Projects** | Statistical analysis of image metadata & word frequency distribution analysis (Zipf's Law and diversity ratio) |

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Libraries**: Pandas, NumPy, SciPy (`scipy.stats`), Matplotlib, Seaborn, PIL
- **Environment**: Jupyter Notebook / Google Colab
