# 📈 Week 07 — K-Nearest Neighbors (KNN) & Distance Measures

This directory contains the **Week 07** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: Week7_KNN_Distance_Measures_Student_Lab_Filled.ipynb

The lab covers the implementation and understanding of the K-Nearest Neighbors (KNN) algorithm and various distance metrics:

| Topic | Description |
|---|---|
| **K-Nearest Neighbors** | Implementing the KNN classification and regression algorithms |
| **Distance Measures** | Understanding and applying distance metrics such as Euclidean, Manhattan, and Minkowski distances |
| **Hyperparameter Tuning** | Finding the optimal value of K and selecting the appropriate distance metric |
