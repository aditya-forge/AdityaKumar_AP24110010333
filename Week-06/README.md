# 📈 Week 06 — Polynomial Regression, Overfitting & Regularization

This directory contains the **Week 06** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: Week6_Polynomial_Regularization_Student_Lab.ipynb

The lab covers polynomial feature engineering, handling non-linear relationships, understanding the bias-variance tradeoff, and applying regularization techniques:

| Topic | Description |
|---|---|
| **Polynomial Regression** | Engineering polynomial features and fitting non-linear relationships with linear regression |
| **Bias-Variance Tradeoff** | Recognizing underfitting and overfitting from train vs. test performance, and explaining the tradeoff |
| **Regularization (Ridge/L2)** | Applying Ridge regularization to fix an overfit model by shrinking weights |
| **Regularization (Lasso/L1)** | Applying Lasso regularization for feature selection (zeroing out weights) |
| **ElasticNet** | Combining L1 and L2 regularization penalties |
