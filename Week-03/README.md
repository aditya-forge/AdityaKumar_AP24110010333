# 📗 Week 03 — Data Preprocessing Hands-On: Getting Data ML-Ready

This directory contains the **Week 03** lab work for the Machine Learning course at SRM University AP.

---

## 📝 Lab Overview

**Notebook**: `Preprocessing_HandsOn_Student_Lab_Completed.ipynb`

The lab covers essential data preprocessing steps required to get data ready for Machine Learning models:

| Topic | Description |
|---|---|
| **Missing Data** | Handling missing data with justified strategies |
| **Encoding Categories** | Label encoding and One-Hot encoding for categorical variables |
| **Feature Scaling** | Min-Max scaling and Standardization |
| **Outlier Detection** | Detecting and handling (capping) outliers using the IQR method |
| **Train/Test Split** | Splitting data correctly before training models |
| **Mini Projects** | Image pixel normalization and text cleaning/encoding |

---

## 🛠️ Tech Stack

- **Language**: Python 3
- **Libraries**: Pandas, NumPy, Scikit-Learn, Matplotlib
- **Environment**: Jupyter Notebook / Google Colab
